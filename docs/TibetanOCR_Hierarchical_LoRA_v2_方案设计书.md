## 二、设计动机

藏文 OCR 领域面临三个独特挑战，驱动了分层 LoRA 设计：

| 挑战 | 问题描述 | 分层策略应对 |
|------|---------|-------------|
| 字形复杂度 | 藏文 30 辅音 + 4 元音 + 上下叠加，远复杂于拉丁字母 | 中层高秩捕获笔画与组合规则 |
| 多语种混合 | 藏+中+英+数字混合场景，模型需要同时理解多种书写系统 | 深层 MLP 高秩建立跨语言映射 |
| 视觉多样性 | 自然场景光照、角度、分辨率变化大 | 浅层低秩保视觉鲁棒性，不过拟合 |

核心假设：**浅层应保守（视觉通用特征），深层应激进（任务特定适配）。**

## 三、核心组件

### 3.1 层级 rank 分配

### 3.2 模块覆盖策略

| 模块 | Shallow | Middle | Deep | 动机 |
|------|:------:|:------:|:----:|------|
| q_proj | ✅ r=8 | ✅ r=24 | ✅ r=48 | 注意力查询，全层必需 |
| k_proj | ✅ r=8 | ✅ r=24 | ✅ r=48 | 注意力键，全层必需 |
| v_proj | ✅ r=8 | ✅ r=24 | ✅ r=48 | 注意力值，全层必需 |
| o_proj | ✅ r=8 | ✅ r=24 | ✅ r=48 | 注意力输出，全层必需 |
| gate_proj | ❌ | ✅ r=24 | ✅ r=48 | MLP 门控，中层起启用 |
| up_proj | ❌ | ✅ r=24 | ✅ r=48 | MLP 上投影，中层起启用 |
| down_proj | ❌ | ✅ r=24 | ✅ r=48 | MLP 下投影，中层起启用 |

浅层不碰 MLP → 保留基座模型的通用视觉-语言理解能力。

### 3.3 LoRA+ 非对称学习率

```
标准 LoRA: η_A = η_B = η
LoRA+:     η_B = λ × η_A  (λ > 1)

分层 λ:
  Shallow: λ = 1.5  (保守)
  Middle:  λ = 2.0  (标准)
  Deep:    λ = 2.5  (激进)
```

理论依据：B 矩阵初始化全零，需要更大学习率才能与 A 矩阵同步收敛。

### 3.4 rsLoRA 秩稳定缩放

```
标准: ΔW = (α/r) × B·A
rsLoRA: ΔW = (α/√r) × B·A

对比 (α=2r):
  r=8:  标准 = 2.0, rsLoRA = 5.66
  r=24: 标准 = 2.0, rsLoRA = 9.80
  r=48: 标准 = 2.0, rsLoRA = 13.86
```

rsLoRA 的关键优势：高秩层获得更大的有效更新幅度，避免"高秩瘫软"。
